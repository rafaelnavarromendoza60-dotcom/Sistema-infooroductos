# Plugin infoproductos

Diecisiete skills en español para investigar, validar, crear, lanzar, vender y escalar infoproductos (ebooks, guías, cursos, plantillas, retos y membresías) en España, Latinoamérica y Estados Unidos. Incluye una skill directora (`director-infoproductos`) que coordina las demás con criterios de aprobación por etapa, y scripts en Python para puntuar ideas, analizar pruebas de validación, calcular la rentabilidad, analizar anuncios y embudos, generar PDF y crear carruseles y mockups.

Uso: describe lo que necesitas ("quiero lanzar un ebook de recetas en México") y Claude usará la skill adecuada, o invócala con `/infoproductos:<skill>`. Los scripts necesitan Python 3; para PDF y PNG, WeasyPrint, Playwright o Chromium.

Documentación completa (instalación, manual de uso, flujos, ejemplos y control de calidad) en la carpeta `docs/` del repositorio raíz.
