# Guiones de vídeo vertical y UGC

## Reel / TikTok educativo (20-45 s)
```markdown
**Título interno:** 
**Objetivo:** [alcance / educación / conversión] · **Duración:** [s]
| Tiempo | Plano / acción | Voz | Texto en pantalla |
|--------|----------------|-----|-------------------|
| 0-2 s | [plano que acompaña al gancho] | [gancho] | [gancho resumido ≤ 7 palabras] |
| 2-8 s | | [problema o promesa del vídeo] | |
| 8-30 s | [demostración / pasos] | [2-3 puntos] | [1 palabra clave por punto] |
| 30-40 s | | [CTA] | [CTA] |
**Pie de publicación:** [primera línea = gancho; 2-4 líneas de valor; CTA; 3-5 hashtags relevantes]
**Sonido:** [voz original / música con licencia comercial]
```

## Anuncio UGC (15-30 s)
```markdown
**Perfil:** [creadora que encaje con el público; real]
| Tiempo | Escena | Diálogo | Texto en pantalla |
|--------|--------|---------|-------------------|
| 0-3 s | Gancho a cámara | "..." | |
| 3-10 s | Problema vivido | "..." | |
| 10-20 s | Mostrar el producto en uso | "..." | [qué incluye] |
| 20-30 s | Beneficio + CTA | "..." | [CTA + garantía real] |
**Indicaciones:** grabación con móvil, luz natural, sin guion leído; la opinión debe ser genuina. Si la creadora recibe pago o producto, debe indicarse según la normativa y la plataforma.
**Hipótesis:** 
```

## Vídeo de demostración (15-30 s)
Plano cenital o pantalla del móvil → abrir el producto → 3 momentos clave (índice, una página, una hoja de trabajo) → texto con el resultado que se obtiene → CTA.

## Buenas prácticas
- Subtítulos siempre (muchas personas ven sin sonido).
- Cambio visual cada 2-4 segundos en piezas de alcance.
- Primer fotograma con texto del gancho (también es la miniatura).
- El final conecta con el principio (favorece el visionado repetido) solo si es natural.
