# Kit promocional y mensajes de captación

## Contenido del kit
1. **Ficha del producto:** qué es, para quién, qué incluye, precio, garantía, enlace de afiliado (cómo obtenerlo).
2. **Ángulos y ganchos** que mejor funcionan (con datos si existen).
3. **Creativos autorizados:** mockups, portadas, carruseles y vídeos cortos con espacio para la voz del afiliado.
4. **Textos para redes:** 3-5 publicaciones de ejemplo para adaptar (no copiar literalmente) con la declaración de afiliado incluida.
5. **Secuencia de 3 emails** para su lista: historia o problema → presentación honesta del producto → recordatorio con FAQ.
6. **Preguntas frecuentes** de compradores y respuestas.
7. **Qué no decir:** promesas prohibidas y frases que infringen las políticas publicitarias.
8. **Calendario:** fechas de lanzamientos o promociones reales.

## Mensaje de captación (primer contacto)
```
Asunto: [Nombre], una colaboración para tu audiencia de [tema]

Hola, [nombre]:

Sigo tu contenido sobre [tema concreto]; tu [publicación o serie] sobre [detalle] me pareció especialmente útil para [público].

He creado [producto], [qué es en una frase] para [público]. Creo que encaja con tu audiencia porque [motivo concreto].

Te propongo:
- Acceso gratuito para que lo pruebes sin compromiso.
- Si te convence, una comisión del [__ %] por cada venta con tu enlace (anulada solo en caso de reembolso).
- Materiales listos para usar y libertad para recomendarlo con tu propia voz.

¿Te envío el acceso?

[Firma]
```

## Seguimiento (si no responde en 5-7 días)
Un único recordatorio breve, aportando algo nuevo (un dato del producto, una pieza útil para su audiencia). No insistas más.

## Página informativa del programa
Titular → para quién es el programa → cómo funciona (3 pasos) → comisión y condiciones → qué recibe el afiliado (kit, acceso, soporte) → reglas → formulario de solicitud → FAQ.
