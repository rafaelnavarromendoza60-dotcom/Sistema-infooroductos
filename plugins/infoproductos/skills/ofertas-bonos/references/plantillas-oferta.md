# Ficha de oferta

```markdown
# Oferta: [nombre del producto]

## Núcleo
- **Público objetivo:** 
- **Problema principal:** [en palabras del cliente]
- **Resultado esperado:** [realista, sin garantía de resultado]
- **Mecanismo o método:** [nombre + cómo funciona en una frase]
- **Entregables:** [formato, extensión, acceso]
- **Diferenciadores:** [frente a 2-3 alternativas concretas]
- **Precio:** [por mercado, con o sin impuestos]
- **Garantía:** [condiciones reales, enlazadas a la política]
- **CTA:** [acción + beneficio]

## Componentes
| Elemento | Obstáculo que resuelve | Cómo ayuda a aplicar | Formato | Valor defendible |
|----------|------------------------|----------------------|---------|------------------|
| Producto principal | | | | |
| Bono 1 | | | | |
| Bono 2 | | | | |

## Complementos
| Tipo | Producto | Precio | Por qué tiene sentido en ese momento |
|------|----------|--------|--------------------------------------|
| Order bump | | | |
| Upsell | | | |
| Post-compra | | | |
| Continuidad (si aplica) | | | |

## Objeciones y respuestas
| Objeción | Respuesta en la oferta (elemento, garantía, prueba, FAQ) |
|----------|-----------------------------------------------------------|

## Comprobaciones
- [ ] Ningún precio de referencia, testimonio, escasez o garantía es ficticio
- [ ] Economía revisada con precios-rentabilidad (valor medio del pedido, margen)
- [ ] La garantía coincide con la política publicada
```

## Variantes para probar (A/B)
- Mismo producto, distinta presentación: "pack completo" frente a "producto + bonos".
- Bono principal distinto según el segmento (p. ej., "rutinas de 10 min" para quien no tiene tiempo).
- Garantía incondicional frente a condicionada (mide conversión **y** reembolsos).
